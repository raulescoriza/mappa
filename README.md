# Mappa

A small, clickable web prototype of a shoulder assessment and exercise flow.
It is a portfolio piece, not a product.

Built with Vite + React + TypeScript (strict), Vitest for unit tests, and
plain CSS with design tokens (no UI library).

## Run

```sh
npm install
npm run dev
```

## Scripts

- `npm run dev` – start the Vite dev server
- `npm run build` – type-check and build a production bundle
- `npm run preview` – serve the production build locally
- `npm run test` – run the unit tests once (Vitest)
- `npm run lint` – lint the project with ESLint
- `npm run format` – format the project with Prettier
